⚠ Read this first

Plugin support in MPC OS 3.10.1 is an experimental feature from Akai, and every plugin is made by an independent developer. A plugin can freeze or restart your MPC. Save your project and back up your drive before you install anything. Akai does not support third-party plugins, and The Disk King does not make, test or guarantee any of them and is not responsible in any way for any damage or loss. Full disclaimer.

1. What you need

  • MPC OS 3.10.1 or later on a standalone MPC or Force.
  • A USB stick or SD card is the easiest way to move plugins over, but not the only one.
  • Know your MPC's generation. It decides which download you pick:
GenerationModelsDownload to pick
Gen1MPC Live, Live II, One, One+, X, X SE, Key 61, Key 37, and the ForceGen1 (file ends in mpc-armv7.zip)
Gen2MPC Live III, One Gen 2, Key 37 Gen 2, XLGen2 (file ends in mpc-aarch64.zip)
BothAny MPC on 3.10.1 or later"Works on both" (file ends in mpc-sdk.zip), if the plugin has one

Your computer plugins won't work here. Standalone MPCs only load plugins built for them with Akai's MPC Plugin SDK. Normal desktop VST3, AU or AAX files from your computer won't load, even if you copy them over. Everything on our list is built for the MPC itself.

2. Update to MPC OS 3.10.1

Check your version under Menu → Preferences → Info. To update, pick one way:

  • On the MPC: connect it to the internet, go to Preferences → Info, press UPDATE, then choose Online Update.
  • From your computer: download the update with the inMusic Software Center.

Heads up from Akai: projects saved in standalone mode on MPC OS 3.4 or later won't open in the old MPC 2.15 desktop software.

3. Turn on plugin support

Plugins are switched off until you turn them on. You only do this once.

  1. Open Menu → Preferences → Enhancements.
  2. In the Enhancements (BETA) section, set Enable Enhancements to On.
  3. Turn on External Plugin Support and accept the warning. Tap the info icon next to any feature to read what it does.
  4. Wait a few seconds, then restart the MPC. If you restart right away, the setting may not save.

4. Pick the right download

  1. Find a plugin on our plugin list. Start with ✓ Tested & Working ones: their makers tested the current version on real hardware.
  2. Open its page. The Download box lists each file by generation: Gen1, Gen2, or "works on both".
  3. Pick the one for your MPC (see the table above). If there's a "works on both" file, it's usually the easiest.
  4. Read the Before you install box. Some plugins need your own files (like a ROM), only run on one model, or need another plugin in the same project.

The download comes straight from the maker's GitHub. Each version shows a SHA-256 checksum, so you can check your file wasn't changed: on Windows, run certutil -hashfile file.zip SHA256.

5. Find the plugin folder

Unzip the download. You're looking for one folder named like Maker - VST - Plugin Name, for example sd88me - VST - Acid. That folder is the plugin. Where it is depends on the download:

"Works on both" (mpc-sdk.zip)

The zip is the plugin folder. Unzip it and that's what you copy.

Drips-1.1.0-mpc-sdk.zip
└─ Padbangers - VST - Drips/   ← copy this

Gen1 / Gen2 (mpc-armv7 / mpc-aarch64.zip)

The plugin folder is inside a folder called portable. Copy only that folder, not the whole download.

Acid-3.0.1-mpc-aarch64.zip
└─ Acid-3.0.1/
   ├─ install.sh, INSTALL.md ...
   └─ portable/
      └─ sd88me - VST - Acid/   ← copy this

Check for a file called plugin.json inside the plugin folder. MPC OS 3.10.1 needs it to list the plugin. Most new releases have one. Some older releases don't, and copying those by hand won't work. They need the maker's installer instead (see the INSTALL.md in the zip), or a newer release. Don't rename mpc-plugin.json to plugin.json: it's a different file, and the plugin still won't show.

6. Copy it to your MPC

Every plugin goes in a folder called VST2 Plugins at the very top of a drive: the MPC's internal drive, an SD card or a USB drive. Type the name exactly, with the space and a capital P. If it isn't there yet, create it. Put each plugin folder directly inside it, not inside another folder.

USB stick (or SD card, or internal drive)
└─ VST2 Plugins/
   ├─ sd88me - VST - Acid/
   │  ├─ plugin.json
   │  └─ ...
   └─ Padbangers - VST - Drips/

Pick one way to get it there:

A. USB stick or SD card (easiest, every MPC)
  1. On your computer, make a VST2 Plugins folder on the stick or card and copy the plugin folder into it.
  2. Plug it into the MPC. The plugin shows up within a few seconds, with no restart needed.
  3. Leave it plugged in. The plugin runs from the stick. If you pull it out while a track uses the plugin, the plugin stops and its screen goes black until you plug it back in.
B. USB cable to the internal drive (Controller Mode)

MPC Live III and MPC XL: both internal drives show up on your computer, as MPC User and MPC Content. On Windows you first need Akai's MPC USB driver from akaipro.com.

  1. Connect the MPC to your computer with a USB cable.
  2. Press Menu, then tap the computer icon at the top right to switch to Controller Mode.
  3. Copy the plugin folder into VST2 Plugins on the MPC User drive. Create the folder if it isn't there.
  4. Eject the drive on your computer, tap Standalone on the MPC and confirm. Restart the MPC if the plugin isn't listed yet, because the internal drive is only read at start-up.

Other MPCs and the Force: the internal drive doesn't show on a computer. Put an SD card or USB drive in the MPC, switch to Controller Mode (Computer Mode on the Force), and copy to that card or drive instead. Leave it in afterwards.

C. Over Wi-Fi (advanced: Developer mode)

Developer mode switches on the MPC's SSH server, letting anyone on your network log in to it. Only use it on a network you trust, and turn it off when you're done.

  1. Hold SHIFT + MENU to enter dev mode, then choose Developer from the mode menu. Note the MPC's IP address (Preferences → Wi-Fi, then hold SHIFT and press the INFO F-key).
  2. In an SFTP app such as WinSCP or FileZilla, connect to that address as user root.
  3. Copy the plugin folder into VST2 Plugins on the internal drive: /nvme/VST2 Plugins/ on a Gen2 MPC, or /sdcard/VST2 Plugins/ on a Gen1 MPC.
  4. Restart the MPC, then turn Developer mode off.

7. Load it on a track

Instruments (synths, drum machines, samplers)

  1. Add a new Plugin track.
  2. In the plugin browser, open External VST Plugins. Plugins are grouped by maker.
  3. Pick the plugin. Its own screen opens, and you play it from the pads or a keyboard like any MPC synth.

Effects (reverb, delay, tape, EQ)

  1. Open the insert effects for a track, pad, program or the master.
  2. Tap an empty insert slot and look for External VST Plugins in the effect browser.
  3. Pick the effect and set it up on its screen or with the Q-Links.
  • MIDI and sequencer plugins can drive your other tracks through their own MIDI port. First turn the port on in Preferences → MIDI, then choose it as the other track's MIDI input.
  • Addins change MPC OS itself rather than going on a track. They install differently, so follow the steps on that addin's own page.
  • Save your project after you add a plugin. The project remembers the plugin and its settings.

8. Update or remove a plugin

  • To update: download the new version and replace the old plugin folder in VST2 Plugins with the new one. If you added your own files to the old folder (ROMs, presets), copy them across first. Then restart the MPC.
  • To remove: delete the plugin's folder from VST2 Plugins and restart. Projects that used it will open without that plugin.
  • Get told about updates: every plugin page has its own updates feed. There's also one feed for every new release: all new releases.

9. Had plugins before 3.10.1?

Before 3.10.1, community plugins were installed a different way, into a Synths folder plus a list in the MPC's settings. On 3.10.1 the browser only lists plugins in VST2 Plugins, so your old ones seem to vanish. Nothing is deleted. The files are still there, and saved projects still open them. To get them back in the browser, copy each plugin folder (the Maker - VST - Name folder from Synths) into VST2 Plugins and restart, or install the plugin's newest release. Keep External Plugin Support turned on: turning it off doesn't bring the old list back.

10. Troubleshooting

The plugin doesn't show in the browser
  • Is External Plugin Support on? Check Preferences → Enhancements.
  • Is the folder named exactly VST2 Plugins, at the top of the drive?
  • Is the plugin folder directly inside it, and named Maker - VST - Name? A common mistake is copying the whole download, so the folder ends up one level too deep.
  • Does the plugin folder have a plugin.json? If not, see step 5.
  • Did you copy to the internal drive? Then restart the MPC, because the internal drive is only read at start-up.
  • Did you pick the right generation? A Gen1 file won't load on a Gen2 MPC, and a Gen2 file won't load on a Gen1 MPC.
The setting won't stay on

Wait a few seconds after switching External Plugin Support on before you restart. The setting is saved a moment later.

It loads but makes no sound, or plays default sounds

Some plugins need files you provide, like a ROM or sound banks. The plugin's page says so in its Before you install box. Put those files where the plugin's own instructions say.

The plugin's screen went black

The USB stick or SD card it runs from was unplugged. Plug it back in. To stop it happening, keep plugins you use a lot on the internal drive.

My MPC froze, crashed or keeps restarting

Restart it. If a project with the plugin crashes every time it opens, take the plugin's folder out of VST2 Plugins (unplug the stick, or use Controller Mode), then open the project again without it. Report what happened on the plugin's page with Report a problem. Include your MPC model, MPC OS version and the plugin version, so the maker can fix it.

It crackles or the MPC slows down

Some plugins use a lot of CPU. Use fewer copies of the plugin at once. Leave Akai's "unlimited tracks" and "remove instance limits" settings off, and if you changed the buffer size in the advanced audio settings, set it larger again.

11. Everything else new in 3.10.1

Plugin support is one of several experimental "Enhancements" in MPC OS 3.10.1. You turn each one on or off separately, in the same Preferences → Enhancements screen:

  • MPC Plugin SDK: Akai's free kit for building your own instrument and effect plugins, even by describing them to an AI coding tool.
  • Mouse pointer: plug in a USB mouse and use it on the screen.
  • Screenshots: press Bank A, B, C and D together to save a PNG of the screen. Hold Shift + a Bank button to choose where screenshots are saved.
  • Unlimited audio and plugin tracks and no instance limits on heavy plugins. These can use more CPU and memory than your MPC has. A project saved with extra tracks loses them if you open it with the setting off.
  • Advanced audio settings: buffer size, latency adjust and sample rate. A smaller buffer means less delay, but too small causes crackles or freezes.
  • Developer panel (hold SHIFT + MENU): an on-screen terminal, system logs, a resource monitor and plugin management. It also turns on SSH. Only use it if you know what you're doing.
  • Remote screen: see, hear and control your MPC from a computer with Akai's MPC Remote Screen Viewer. Only use it on a network you trust.

12. Stay safe

  • Pick ✓ Tested & Working plugins first. Their makers tested the current version on real hardware. Treat ⚠ Experimental / Untested ones as risky.
  • Read the Safety check on each plugin page. We download every release, check the file matches its checksum and is built for your MPC, and point out anything that needs a closer look, like a plugin that uses your network.
  • Save and back up before you try a new plugin, and try it on a test project first.
  • Turn off Developer mode and remote screen when you're not using them.
  • Only download from the maker's own GitHub, which is where every download on our list comes from.
