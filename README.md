# MPC Plugins

**The complete, auto-updating list of plugins for Akai MPC and Force.** By [The Disk King](https://thediskking.com/).

Browse it at **https://mpcplugins.github.io/**

- Every night the tracker searches GitHub for MPC and Force plugins, checks each one's newest release, and rebuilds the list.
- Instruments, effects and addins for the MPC Live, Live II, Live III, One, X, Key and Force.
- Downloads come straight from each maker's own GitHub.
- The list is published as `catalog.json` at https://mpcplugins.github.io/catalog.json

## Makers: get listed

Nothing to sign up for. Publish a GitHub release with your MPC build zips, named like
`YourPlugin-1.0.0-mpc-armv7.zip` (Gen1) and `YourPlugin-1.0.0-mpc-aarch64.zip` (Gen2), or `YourPlugin-1.0.0-mpc-sdk.zip`
for an Akai SDK build. Your plugin shows up within a day. To fix a name, description or category, email
thediskking@gmail.com.
